הכול רץ בחינם על GitHub, בלי מחשב דלוק ובלי שרת.

## איך זה מקבל נתונים?

GitHub מריץ את הקוד על שרת בענן שיש לו אינטרנט. הקוד מוריד בעצמו:
רשימת המניות משרת ה-screener של Nasdaq, ומחירים, נפחים, דוחות ותאריכי דוחות מ-Yahoo Finance (ספריית `yfinance`, בלי מפתח).
כל החישובים נעשים שם, והתוצאה נשמרת כדף אינטרנט (GitHub Pages).

## הקמה (פעם אחת, ~15 דקות, עדיף ממחשב)

1. **חשבון GitHub** – נרשמים בחינם ב-https://github.com/signup.
2. **מאגר חדש** – למעלה ➕ ← *New repository* ← שם: `stock-radar` ← **Public** ← *Create repository*.
3. **העלאת הקבצים** – *uploading an existing file* ← לגרור את **כל התוכן** של התיקייה `stock-radar` מהזיפ ← *Commit changes*.
4. **קובצי התזמון** – תיקייה שמתחילה בנקודה (`.github`) לפעמים לא עולה בגרירה. אם במאגר אין תיקייה `.github`,
   יוצרים שלושה קבצים: *Add file* ← *Create new file* ← שם הקובץ בדיוק כמו בטבלה ← מדביקים את התוכן מהקובץ המקביל בתיקייה `workflows_copy`:

   | שם הקובץ במאגר | התוכן מהקובץ |
   |---|---|
   | `.github/workflows/daily.yml` | `workflows_copy/daily.yml.txt` |
   | `.github/workflows/notify.yml` | `workflows_copy/notify.yml.txt` |
   | `.github/workflows/backtest.yml` | `workflows_copy/backtest.yml.txt` |

5. **הרשאת כתיבה** – *Settings* ← *Actions* ← *General* ← *Workflow permissions* ← **Read and write permissions** ← *Save*.
6. **הפעלת האתר** – *Settings* ← *Pages* ← *Deploy from a branch* ← `main` / `/docs` ← *Save*.
7. **טלגרם** – ראו בהמשך.
8. **הרצה ראשונה** – לשונית *Actions*:
   - *Weekly backtest* ← *Run workflow* (30–90 דקות; מכייל את המשקלות).
   - אחרי שהסתיים: *Daily stock radar* ← *Run workflow* (20–45 דקות).
   - *Morning Telegram alert* ← *Run workflow* – בדיקה שההודעה מגיעה.
9. **הדשבורד** – `https://<שם-המשתמש>.github.io/stock-radar/` – "הוסף למסך הבית" בטלפון.

### הגדרת טלגרם (5 דקות, מהטלפון)

1. בטלגרם מחפשים **@BotFather** ← `/newbot` ← בוחרים שם (למשל "הרדאר שלי") ושם משתמש שמסתיים ב-`bot`.
   מקבלים **טוקן** שנראה כמו `123456789:AAH...` – להעתיק.
2. פותחים את הבוט החדש ולוחצים **Start** (אחרת הוא לא יכול לשלוח לך).
3. מחפשים **@userinfobot** ← Start ← הוא מחזיר את ה-**Id** שלך (מספר) – להעתיק.
4. ב-GitHub: *Settings* ← *Secrets and variables* ← *Actions* ← *New repository secret*, פעמיים:
   - שם `TELEGRAM_TOKEN`, ערך: הטוקן.
   - שם `TELEGRAM_CHAT_ID`, ערך: המספר.

הטוקן נשמר מוצפן ב-GitHub ולא מופיע בקוד. אם לא מגדירים טלגרם – הכול עובד, פשוט בלי הודעה.

## התיק שלי

עורכים את הקובץ `portfolio.csv` ישירות באתר GitHub (אייקון העיפרון). שורה לכל מניה:

```
ticker,buy_price,buy_date,shares,stop,notes
NVDA,120.50,2025-06-10,20,,
ESLT.TA,145000,2025-09-01,3,,מחיר ת"א באגורות
MSFT,410,2025-03-02,5,380,סטופ ידני
```

רק `ticker` ו-`buy_price` חובה. בלי `stop` – הסטופ הוא 8% מתחת למחיר הקנייה (כלל O'Neil). דוגמה: `portfolio.example.csv`.

לכל מניה בתיק הכלי בודק כל בוקר: 🔴 **מכירה** – הסטופ נפגע / נשברה מתחת לממוצע 150 / שלב 4 ·
🟠 **אזהרה** – מתחת לממוצע 50, חלוקה מוסדית, דוח רבעוני בקרוב · 🔵 **לתשומת לב** – רווח מעל 20% (לשקול מימוש חלקי) ·
🟢 **להחזיק** – המגמה תקינה. אותות מכירה ואזהרה מופיעים גם בהודעת הטלגרם.

## השיטה

| רכיב | משקל התחלתי | מקור |

| מגמה | 20% | ממוצע 150 ושלב 2 (Stan Weinstein), Trend Template של Mark Minervini |

| חוזק הענף | 12% | IBD Industry Group Rank – חציון החוזק היחסי של המניות בכל תעשייה |
| דמיון למנצחות | 12% | טביעת אצבע טכנית של 18 מניות לפני ריצות ענק, מחושבת מנתוני אמת |
| מבנה / תבנית | 12% | פיבוט, VCP, פריצה בנפח, וזיהוי כוס וידית / בסיס שטוח / תחתית כפולה / דגל גבוה וצר |

- רק מניות **בשלב 2** (מעל ממוצע 150 שעולה) עם נזילות מספקת נכנסות לבחירה. בטופ 10 – עד 3 מניות מכל קטגוריה.
- מניה שמפרסמת **דוח בתוך 5 ימים** מקבלת הורדה בציון; עד 10 ימים – אזהרה בכרטיס ובטלגרם.

### בדיקה לאחור וכיול

פעם בשבוע הכלי "חוזר בזמן": בכל חודש ב-8 השנים האחרונות הוא מחשב את הציונים רק מהמידע שהיה ידוע באותו יום,
בוחר 10 מניות ומודד מה עשו בחודש שאחרי מול S&P 500. אחר כך הוא מנסה 400 צירופי משקלות על 65% הראשונים של התקופה,
ובודק את הטוב ביותר על 35% האחרונים שלא ראה. משקלות חדשים מאומצים (בחצי הדרך מברירת המחדל) **רק אם שיפרו גם בתקופה שלא נראתה**.
בדשבורד רואים: תשואה שנתית, ירידה מקסימלית, אחוז חודשים שהיכו את השוק, עקומת הון, וכמה כל רכיב "מנבא".

מגבלות: הטיית שורדים (נבדקות רק מניות שקיימות היום – מנפח תוצאות), אין נתונים פונדמנטליים היסטוריים בחינם,
תבניות גרף לא נבדקות, בלי עמלות ומסים. להתייחס לתוצאה ככיוון, לא כהבטחה. כיבוי הכיול: `USE_CALIBRATED_WEIGHTS = False` ב-`screener/config.py`.

## רשימת מעקב לפי תחומים + התראות בדחיפה
- עורכים את `watchlist.csv` (עמודות: sector, ticker, note). אפשר לשנות תחומים ולהוסיף מניות ת"א עם סיומת `.TA`.
- `watch.yml` רץ כל שעה בזמן המסחר בוול סטריט ושולח לטלגרם רק אירועים **חדשים**:
  חצייה של ממוצע 20 (מיכה), תיקון לממוצע 20 אחרי עלייה, שבירת 50/150, תנועה של ±5% (בנפח חריג = דחוף), פריצה מתבנית, שבירת קו מגמה, ראש וכתפיים.
- לכל מניה: המלצה (קנייה/הוספה · החזקה · המתנה · צמצום · יציאה), כניסה/סטופ/יעד וטיוטת פקודה.
- אופציונלי: משתנה `ACCOUNT_SIZE` (Settings → Variables) לחישוב כמות לפי סיכון 1% לעסקה. `WATCH_MIN_URGENCY=3` = רק התראות דחופות.
- הביצוע תמיד ידני אצל הברוקר.
