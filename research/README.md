# מודול המחקר – "חדר המחקר"

מודול נפרד מהסורק היומי. הסורק (GitHub Actions) מחשב מספרים; מודול המחקר קורא **אמירות רשמיות** ומודד מה המניות עשו אחריהן.

- **איפה רואים:** דף "חדר המחקר" ב-claude.ai (הקישור מופיע בכותרת הדשבורד כשמגדירים `RESEARCH_URL` ב-`screener/config.py`).
- **מי מריץ:** משימה מתוזמנת של Claude כל בוקר, עם צוות סוכנים מומחים (קבצי ההגדרה בתיקייה `agents/`).
- **כללי מקורות:** `agents/_common.md` – רק מקורות רשמיים, ציטוט דרך Reuters/Bloomberg/CNBC/WSJ/AP/FT רק כשהם מצטטים פוסט/מסמך רשמי.
- **תחזיות:** כל תחזית נרשמת עם תאריך, תזה ותנאי הפרכה, ונסגרת כפגיעה/החטאה אחרי האירוע.
- **מתודולוגיות:** `methodologies.json` – כללים שאומתו ממקורות רשמיים של מיכה סטוקס וד"ר ינון אריאלי, עם סימון מה כבר קיים ברדאר.
